Anchore tag


The HTML element (or anchor element), with its href attribute, creates a hyperlink to web pages, files, email addresses, locations in the same page, or anything else a URL can address. Content within each should indicate the link's destination. If the href attribute is present, pressing the enter key while focused on the element will activate it
